Scripts for exporting data from a Greenplum database to Parquet files and for loading data from Parquet files into a Greenplum database. 
These have been tested using sample data. 
Use them in a production environment at your own risk—be sure to test them with your own data first! 
The scripts were run on Ubuntu Linux. 
Since they are written in Python, they might theoretically work on other operating systems, but this has not been verified!
